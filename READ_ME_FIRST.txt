BUDGETWISE — SHARED PROJECT FOLDER

HOW TO RUN — NO INSTALLATION NEEDED
1. Download the ZIP and choose Extract All.
2. Open the extracted BudgetWise_Shared_Project folder.
3. Double-click BudgetWise.html and open it in Chrome or Edge.
4. Click Load example data to explore, or enter your own transactions.

Do not open the app inside the ZIP or an email/file preview. Extract first.
Use BudgetWise.html at the top of this folder. App_Source/dist/index.html is the developer version and requires an HTTP server.

SHARING
Send this ZIP, or copy the complete extracted folder to another PC.
The portable app contains its own styles, code and chart library; no internet connection is needed for its built-in features.
Each browser/PC keeps its own records. Sending the folder does not copy your current spending records.
To share or move entered records, use Export backup in the app and then Import on the other PC. Import asks before replacing data.
The app does not sync data between people. Browser settings may prevent local saving; the app reports save failures. Export a backup before moving/renaming the HTML file or clearing browser data.
